# Icon Guide - Lucide Icons

Complete guide for using icons in your links.

## What are Lucide Icons?

Lucide is a beautiful, consistent icon set with over 1,000+ icons. This project uses Lucide Icons for link icons.

**Official Website:** https://lucide.dev/icons

## How to Use Icons

### 1. Browse Available Icons

Visit https://lucide.dev/icons to browse all available icons.

**Popular Categories:**
- **Social Media**: Github, Linkedin, Twitter, Instagram, Youtube, Facebook
- **Communication**: Mail, Phone, MessageCircle, Send
- **Web**: Globe, Link, ExternalLink, Home
- **Media**: Camera, Video, Music, Image
- **Business**: Briefcase, Building, ShoppingCart, CreditCard
- **Development**: Code, Terminal, Database, Server
- **Files**: File, FileText, Download, Upload
- **Navigation**: ArrowRight, ChevronRight, Menu, Search

### 2. Add Icon to Link

When creating or editing a link:

1. Click "Add Link" or edit existing link
2. Find the "Icon (Lucide name)" field
3. Click the link to browse icons: **lucide.dev/icons**
4. Search for your desired icon
5. Copy the icon name (e.g., "Globe", "Github", "Mail")
6. Paste it in the Icon field
7. Save your link

**Example:**
```
Icon field: Globe
Icon field: Github
Icon field: Mail
```

### 3. Icon Name Format

**Important Rules:**
- Use PascalCase (first letter uppercase)
- No spaces
- Exact spelling matters

**Correct Examples:**
```
Globe
Github
Linkedin
Mail
ExternalLink
MessageCircle
ShoppingCart
```

**Incorrect Examples:**
```
globe          ❌ (lowercase)
git hub        ❌ (space)
linked-in      ❌ (hyphen)
email          ❌ (wrong name, use "Mail")
```

## Troubleshooting

### Icon Not Showing

**Problem:** Icon field filled but icon doesn't appear

**Solutions:**
1. Check spelling - must be exact
2. Use PascalCase (e.g., "Github" not "github")
3. Verify icon exists on lucide.dev
4. Try a different icon to test

### Wrong Icon Appears

**Problem:** Different icon than expected

**Solutions:**
1. Double-check icon name on lucide.dev
2. Some icons have similar names
3. Clear and re-enter icon name

### Can't Find Icon

**Problem:** Looking for specific icon

**Solutions:**
1. Use search on lucide.dev/icons
2. Try alternative keywords
3. Check similar categories
4. Use generic icon (e.g., "Link", "ExternalLink")

## Best Practices

### Do's ✅

- Use relevant icons for your links
- Keep icon names consistent
- Test icons after adding
- Use recognizable icons for social media
- Browse lucide.dev before choosing

### Don'ts ❌

- Don't use random icons
- Don't misspell icon names
- Don't use lowercase
- Don't add spaces or hyphens
- Don't use icons that don't exist

## Icon Fallback

If no icon is specified or icon name is invalid:
- Default link icon (🔗) will be shown
- Link still works normally
- You can add/fix icon later
